# Period landing

Лендинг бота Period. Дизайн как у Mini App: тёмный фон, серебро, Playfair Display и знак-орбита.

Анимации в духе [React Bits](https://reactbits.dev/): Silk, Spotlight Card, Blur Text, Count Up. Блоки как на [Pro Blocks](https://pro.reactbits.dev/docs/blocks): Hero, How it works, Features, Stats, Pricing, FAQ, CTA. Исходники Pro не копировались.

```bash
cd landing
npm install
npm run dev
```

Прод:

```bash
npm run build
```
